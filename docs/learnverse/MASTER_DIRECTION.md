# LearnVerse AI — Master Direction

LearnVerse AI is the public product. EDUNEXUS and AIESES are foundations whose useful capabilities are being consolidated into one ecosystem. SIH 2026 is no longer a product constraint.

## Product roles
- LearnVerse = product identity + adaptive learning intelligence.
- EDUNEXUS = existing education/product capabilities reused and refactored.
- AIESES = existing adaptive, multilingual, AI, assessment and workspace capabilities reused where valuable.

## Experience
3D is the primary experience for exploration: home universe, technology worlds, skill graph, roadmap, missions and mastery. 2D remains the default for reading, coding, assessments, documents, settings and accessibility fallback.

## Core loop
SOURCE → UNDERSTAND → PERSONALIZE → TEACH → PRACTICE → ASSESS → DIAGNOSE → REPAIR → BUILD → MASTER → NEXT BEST SKILL

## First implementation target
Prove one complete loop in the existing EDUNEXUS foundation:

goal → skill graph → learning resource → Learn This → practice → assessment → evidence → Skill DNA → next best action

## Non-negotiables
- Unknown skill is not treated as weak.
- AI output must be grounded/validated where applicable.
- User content is data, not trusted instructions.
- Arbitrary user code must not execute on the application server.
- Generated material preserves provenance.
- 3D never blocks core learning.
- Public deployment is production-oriented, not a hackathon demo.
